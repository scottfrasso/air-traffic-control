# 2026-10-24: The $5 nobody asked for, and taking it all down

The Cloudflare bill showed about $5, almost all "Container Memory, per GiB-Second". Nothing should have been running.

It was our own safety net. Main is protected by a timer that checks it every two minutes and puts it back if someone
pushed straight to it. One test repo was in a state that could never be put back (we'd broken it on purpose, before
the fix that makes that recoverable). So every two minutes, forever, the timer tried again, and every try woke an
8 GiB container. The container goes to sleep after ten idle minutes. Woken every two, it never slept: about 7 cents
an hour, per instance, all night. A day of that cost about as much as the whole week of AI code reviews.

The fix is boring and right: a retry that keeps failing waits longer each time (1 hour, 2, 4, up to once a day). And
a rule for the future, written into ADR-0032: every timer or retry that can start something billed by the second has
to say, before it ships, what one firing costs and what happens when it fails every single time.

Then, going on vacation, we took everything down: both Workers, every queue, workflow, subscription and container.
Nothing can run, bill or be attacked while we're away. The code, the tests and the diary are all in git; bringing it
back is three commands.
