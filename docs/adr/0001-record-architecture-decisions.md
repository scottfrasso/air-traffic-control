# ADR-0001: Record architecture decisions

- Status: Accepted
- Date: 2026-10-10

## Context
The prompt asks for autonomous work, with ambiguity resolved by picking the simplest option that keeps the demo working.
Those choices need to be reviewable later.

## Decision
Each significant decision is a numbered ADR in `docs/adr/` (Context / Decision / Consequences).
`DECISIONS.md` at the repo root is the index plus spike findings, as prompt.md requires.

## Consequences
Reversing a decision means writing a new ADR that supersedes the old one, not editing history.
